All of these came from Unsplash, filtered to the free licence
(unsplash.com/license). That licence grants free commercial use and asks
for no attribution, so nothing on the page credits them. This file exists
anyway, so the source of a picture is never a mystery later.

The Unsplash+ / Getty results were deliberately excluded: those are a paid
licence and are not covered by the free one.

Each file was fetched from Unsplash's image CDN already cropped to 16:9,
which is why they need no processing here:
